## مرزهای ایمنی و موارد باز
- پلن فعال فعلاً برای همه حساب‌ها Free است. Pro/VIP در رابط معرفی شده‌اند اما خرید/فعال‌سازی ندارند.
- قفل امکانات فعلی در سمت مرورگر برای تجربه کاربری است، نه مجوز امنیتی قابل اتکا. پیش از فروش باید entitlement سمت سرور، RLS/RPC امن، سوابق تغییر پلن و اتصال پرداخت طراحی و روی محیط آزمایشی تست شود.
- قیمت هشدارها هر ۳۰ ثانیه از فید بازار دریافت می‌شود؛ هشدار پس‌زمینه/Push هنگام بسته بودن برنامه و همگام‌سازی هشدارها بین دستگاه‌ها هنوز وجود ندارد.
- هشدارها در localStorage همان مرورگر/دستگاه ذخیره می‌شوند.
- هیچ جدول، migration، RPC، تنظیم Auth یا داده‌ای در Supabase Production تغییر نکرده است.
- `main` تغییر نکرده و هیچ PR ادغام نشده است.
